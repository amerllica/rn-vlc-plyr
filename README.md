# rn-vlc-plyr

React Native VLC Player (Video/Audio) based on VLC, powered by Nitro Modules

## Installation


```sh
npm install rn-vlc-plyr react-native-nitro-modules

> `react-native-nitro-modules` is required as this library relies on [Nitro Modules](https://nitro.margelo.com/).
```


## Usage


```js
import { RnVlcPlyrView } from "rn-vlc-plyr";

// ...

<RnVlcPlyrView color="tomato" />
```
