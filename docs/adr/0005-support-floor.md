# 0005. Support floor

Status: accepted (2026-10-07)

## Context

Nitro views need RN 0.78 or newer. Expo SDK 53 is the first with the new architecture on by default.

## Decision

Support RN 0.79 or newer, Expo SDK 53 or newer, new architecture only, iOS 16 or newer, Android API 24 or newer. The npm name stays `rn-vlc-plyr`; the rewrite ships as 1.0.0.

## Consequences

The old architecture and web are not supported.
